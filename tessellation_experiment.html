Notes

• “Periodic” grids (squares, triangles, hexagons) repeat by translation.
• “Penrose Rhombs” is an aperiodic tiling from two rhombi (thick & thin) via inflation rules; cells won’t line up in a repeating grid.
• Each cell gets a pseudo-random color (seeded), so the same seed reproduces the same colors.
